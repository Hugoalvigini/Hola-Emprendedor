## Qué es Hola Emprendedor

Hola Emprendedor es el curso de entrada de Hugo Alvigini Academia para emprendedores que hacen todo a mano, están desordenados y quieren empezar a ordenar su negocio y hacer que las herramientas trabajen como un sistema, sin depender de suscripciones eternas.

No es un curso teórico de motivación. Es el punto de partida práctico: cómo empezó Hugo, qué hizo para lograr su primera venta internacional y qué podés hacer hoy para ordenar tu negocio.

## Para quién es

Para vos si:
* Sos emprendedor o tenés un negocio chico y hacés todo vos.
* Perdés tiempo con planillas, mails y tareas manuales.
* Querés automatizar pero no sabés por dónde empezar.
* Querés aprender con ejemplos reales, no con teoría.

No es para empresas que ya tienen sistemas armados ni para quienes buscan una solución mágica sin implementar nada.

## Qué incluye el curso

**Módulo 0 - Lección 0: Bienvenida**
Presentación del curso y cómo aprovecharlo.

**Módulo 1 - Lecciones 1 a 4: Mi historia**
La historia real de Hugo Alvigini: cómo empezó, cómo consiguió su primera venta internacional con Fimendra y qué hacer hoy después de dar ese primer paso. Incluye la lección `¿Qué hago hoy después de Fimendra?`

**Módulo 2 - Plantilla 1 y 2**
Dos plantillas prácticas para empezar a ordenar tu operación.

**Módulo 3: Cómo seguir después del curso**
Explicación de los 3 caminos para seguir trabajando con Hugo:
* **Consultorías 1 a 1:** para arreglar partes de tu proceso para que las herramientas funcionen como un sistema.
* **Packs:** 3 cursos secuenciales: 1. Investigación de Mercado, 2. Páginas web como webapps, 3. Automatizaciones.
* **Clases Grupales:** para equipos que necesitan optimizar un proceso real trabajando sobre ese proceso.
